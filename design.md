# DESIGN.md — Premium Malay Batik & Songket Perfume Catalogue

## 1. Project Overview

Build a **high-end perfume brand catalogue website** with a luxurious, premium, rich, and editorial visual atmosphere.

The website should feel like a fusion of:

- Luxury niche perfumery
- Premium fashion houses
- Malay heritage
- Traditional **Batik**
- Traditional **Songket**
- Modern editorial web design

This is **NOT an e-commerce checkout website**.

The main purpose is to:

1. Present the perfume brand beautifully.
2. Showcase perfume collections and individual fragrances.
3. Communicate the story, identity, craftsmanship, notes, mood, and character of each fragrance.
4. Create a memorable premium brand experience.
5. Encourage customers to contact the business or visit its social channels to order or enquire.

---

# 2. Critical Product Rule

## This website is a catalogue only.

Do **NOT** implement:

- Shopping cart
- Shopping bag
- Checkout
- Payment gateway
- Quantity selector
- Add to cart button
- Cart icon
- Order subtotal
- Shipping calculator
- Billing form
- Payment form
- Stock counter
- E-commerce checkout flow

If a call-to-action is needed, use catalogue-friendly actions such as:

- `View Fragrance`
- `Discover`
- `Explore Collection`
- `Enquire`
- `Contact Us`
- `Order via WhatsApp`
- `Visit Instagram`

The overall experience should behave like a **luxury perfume showroom / digital catalogue**, not an online store.

# 5. Design Balance

Heritage motifs should support the perfume presentation rather than compete with it.

Recommended balance:

- Large perfume imagery = visually dominant
- Typography = elegant and spacious
- Batik/Songket details = decorative layer
- Gold accents = selective
- Motion = slow and graceful
- UI controls = minimal

Avoid covering every surface with patterns.

A good principle:

> Use Batik as artistic expression and Songket as architectural structure.

For example:

- Batik works beautifully as soft floral backgrounds and image framing.
- Songket works beautifully as borders, grids, gold lines, and structured ornamental details.

5. Make the entire site responsive.
